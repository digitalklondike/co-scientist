# Co-Scientist — локальный UX-прототип

Рабочая версия: http://127.0.0.1:4187/

Прототип сохраняет светлый интерфейс и основную структуру Bayer AI Co-Scientist из видео. Главная адаптирована по визуальным референсам Elicit, Hex и Intercom, выбранным в обсуждении.

## Что применено

Типографика обновлена по обратной связи: UI — 12 px, основной текст и ввод — 16 px; 14 px и видимый текст мельче 12 px исключены. Заголовки используют 24/32 px. Размеры заданы общими CSS-токенами и сохраняются на телефоне.

| Зона из разговора с клиентом | Реализация |
|---|---|
| Непонятно, что можно спросить | Собственный вопрос — главное действие; краткое объяснение возможностей; редактируемые примеры по трём типам задач |
| Пользователи работают только с примерами | Пример заполняет поле и остаётся редактируемым; запуск — отдельное осознанное действие |
| Onboarding в первом исследовании | Практическое сопровождение в чате: возможности и свой вопрос → краткий результат и реальные источники → необязательное сохранение в Notebook. Нейтральные сообщения вместо синих учебных плашек. Текущая фаза видна; пример редактируется без отправки. После сохранения — Continue in Notebook / Finish guide, без четвёртого обязательного задания. Обновление возвращает начало демо, сохраняя данные. |
| Notebook не замечают | Основная навигация и сохранение рядом с ответом; короткая контекстная подсказка до первого сохранения |
| Повторы в оболочке | Пять последних уникальных вопросов без повторяющихся категорий и Today; остальные доступны через Show all research. Один аватар слева внизу, без линии над профилем |
| Проверка онбординга на исходном экране ответа | Восстановлена структура сообщения из видео: Direct answer, доказательства и Conclusion обычным текстом; Sources used одной строкой; Notebook и экспорт внизу; рекомендованные вопросы после сообщения. Только подсказки у Sources used и Notebook относятся к онбордингу |
| Долгое ожидание и технические статусы | Понятные этапы, отмена, возможность продолжить работу и открыть готовый результат |
| Простая задача вызывает сложный анализ | CSV получает описательные статистики: число значений, среднее, минимум, максимум и пропуски |
| План требует текстового подтверждения | Кнопки Confirm and start и Edit question перед гипотезами |

## Границы демонстрации

- Литературные ответы и гипотезы — подготовленные примеры. Пользовательский вопрос сохраняется, но не отправляется в AI. Для вопроса вне темы пример явно обозначается как неподходящий ответ.
- Ссылки в литературном примере ведут к оригинальным статьям PubMed. Это не актуальный поиск и не полный обзор литературы.
- CSV до 2 MB обрабатывается в браузере: расчёты реальные, пустые значения исключаются независимо для каждого столбца. Текстовые столбцы не анализируются как числа.
- Notebook, вопросы и заметки сохраняются в localStorage этого браузера. Это не серверная база и не совместная работа.
- Интеграции с внутренними системами клиента отсутствуют и отмечены как Not connected.

## Проверка

Для демонстрации помощь в первом исследовании снова доступна после обновления страницы, даже если до этого была завершена или пропущена. Вопросы, Notebook и заметки сохраняются как прежде. Открытие источников отмечает взаимодействие с разделом, а не научную проверку доказательств.

В браузере проверены редактирование примера, запуск, раскрытие доказательств и источников, сохранение ответа, заметка и её восстановление после перезагрузки, экспорт Markdown, CSV с кавычками и пропусками, ошибка неверного CSV, подтверждение/редактирование плана и работа в фоне. Снимки находятся в `verification/`; итог визуальной проверки — в `design-qa.md`.

## Локальная разработка

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4187 --strictPort
```

```powershell
npm run build
```

Весь интерфейс пересобран на [shadcn/ui](https://ui.shadcn.com/): Sidebar/Sheet, Tabs, поля, кнопки, Dialog, Select, Accordion, Table, Card, Progress, Tooltip и Alert. React + Vite, Tailwind v4, локальный Inter и Lucide Icons. Старые styles.css и readability.css больше не подключаются. Названия чатов — одна строка с многоточием и полным вопросом в tooltip. Видимый логотип извлечён из предоставленного видеоряда. Приложение не публиковалось.
